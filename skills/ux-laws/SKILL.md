# UX laws

Apply psychology as reasoning, not decoration. Read references/laws.md for the full set with definitions, applications, and limits. When invoking a law:

1. Name it and state it in one line.
2. Show the mechanism in THIS design ("14 equally weighted menu items - Hick's law predicts slower, more anxious choices").
3. Give the bounded recommendation - every law has limits; cite them (Hick's doesn't apply to ordered lists users scan alphabetically).
4. Note tensions when laws conflict (Fitts's wants big targets; density wants compact - resolve by frequency of use).

Never law-drop as authority without the mechanism. Laws explain and predict; evidence from research and analytics still outranks them when available.

Covered in references/laws.md: Hick's, Fitts's, Miller's chunking, Jakob's, Tesler's, Doherty threshold, Von Restorff, aesthetic-usability effect, peak-end rule, proximity, common region, serial position, Zeigarnik, Postel's, goal-gradient.
