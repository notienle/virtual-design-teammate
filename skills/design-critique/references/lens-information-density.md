# Lens: information density and cognitive load

Evaluate load, prioritization, scannability, progressive disclosure.

- **Density fit to job.** Monitoring and comparison jobs want high density; decision and learning moments want focus. The finding is mismatch, not density itself - a sparse table merchandisers scan all day wastes their time; a dense first-run screen overwhelms.
- **Prioritization evidence.** Top-left/first-viewport content should be the highest-frequency or highest-stakes information (cross-check product-analytics when contested). Everything visible should earn its place: for each element ask "who needs this, how often" - can't answer = candidate for disclosure or removal.
- **Scannability mechanics.** Can a user find one known item in under ~5s: consistent row anatomy, aligned scan columns, keywords front-loaded in labels, visual anchors every 5-9 rows (grouping, zebra only when rows are wide).
- **Progressive disclosure health.** Summary -> detail layering: overview answers the common question, details one interaction away (expand, panel, drill-in) without losing context. Flag both failure modes: everything-upfront walls and over-hidden (3 clicks to a daily-needed value).
- **Redundancy and noise.** Repeated labels, decorative icons carrying no meaning, borders+background+shadow doing one job, units repeated per cell instead of per column.
- **Numbers legibility.** Comparable figures aligned, consistent precision, thousands separators, deltas marked with direction+magnitude not color alone.
